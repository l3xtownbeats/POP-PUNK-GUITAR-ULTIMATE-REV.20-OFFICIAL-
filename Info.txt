## 2. Зафиксированная продуктовая база
- Формат: VST3 x64; целевая ОС: Windows 10 x64; обязательный хост-приёмщик: FL Studio 20 x64.
- Главные режимы только два: MELODY и PATTERN.
- AUTOCHORDS — дополнительное окно внутри PATTERN, не третий главный режим.
- В обоих режимах MIDI-клавиша запускает один конкретный mapped note/event clip, а не полный LOOP/RIFF/phrase. Whole-take/phrase preview — отдельное действие в браузере.
- Factory bank: ровно 500 базовых presets как целевая комплектация — 250 MELODY + 250 PATTERN. PATTERN-каталог обязательно распределяется по своим окнам/разделам/функциям; запрещён один плоский список из 250 элементов. Каталог может расширяться сверх базовых 500.
- Один общий Sample Engine; WAV/SFZ, voice allocation, velocity mapping, background streaming/page cache и bounded queues.
- Задачи файловой системы, сканирование, hashing и загрузка выполняются вне audio callback.
- Утверждённый визуальный эталон: NEON STAGE DEFAULT / SKIN-1 / stable ID skin-053.
- Продукт содержит ровно 16 логических тем SKIN-1…SKIN-16; registry index не является логическим номером темы.
- 27 пользовательских control IDs и семь утверждённых FX bypass IDs не изменять без отдельного утверждения.
- Сэмплы допускаются в распространяемый продукт только при CC0/PD, иной лицензии с явным правом bundle/redistribution либо письменном разрешении правообладателя.
