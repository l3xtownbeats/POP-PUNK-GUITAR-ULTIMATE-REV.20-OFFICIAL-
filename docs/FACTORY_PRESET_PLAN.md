# Factory Preset Plan

## Core requirement

Create and integrate **500 core factory presets** based on the BASIC LIBRARY. All 500 must be usable with the 10–12 GB BASIC LIBRARY installed; none may depend on the EXPANDED LIBRARY.

## Dependency and test gate

Preset authoring/integration follows sample-library intake, license review, and sample mapping. Do not run plugin, preset, audio-engine, sound-quality, or final-build tests until:

- The BASIC LIBRARY has been assembled and integrated.
- All 500 core factory presets have been created and integrated.

## Preset design principles

- Deliver ready-to-play pop-punk guitar sounds suitable for immediate MIDI keyboard use.
- Cover rhythm, power-chord, octave, lead, muted/palm-muted, slide, sustain, and acoustic guitar roles where supported by cleared source material.
- Include the approved genre/reference range: Blink-182, Sum 41, Simple Plan, New Found Glory, Good Charlotte, Mest, Angels & Airwaves, The All-American Rejects, MGK, and later-era Avril Lavigne.
- Preserve clear distinctions between tone, articulation, playing role, and mix position; avoid filling the 500 slots with trivial name-only variations.
- Use only sample content available in BASIC LIBRARY for the 500 core presets.
- EXPANDED LIBRARY may provide alternate takes, extra layers/variations, and additional banks, but must not become a dependency of core presets.
- Do not represent unsupported articulations or features as implemented.

## Catalog status

No actual preset definitions or preset files were present in the repository at initial inspection. The 500-preset catalog has therefore **not** been marked as created. Populate the catalog only after sample assets have been reviewed and mapped; record each preset's sample dependencies and required library tier.
