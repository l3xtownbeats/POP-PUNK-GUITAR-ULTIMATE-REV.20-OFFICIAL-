# PPGU NEON STAGE DEFAULT — Manager skin assets

This folder contains the visual-only PPGU theme source used by Library Manager 3.0.

- User-facing slot: **SKIN-1**
- Canonical manifest ID: skin-053
- Canonical theme name: **NEON STAGE DEFAULT**
- Source repository: l3xtownbeats/POP-PUNK-GUITAR-ULTIMATE-4.0-VST-L3XTOWN-
- Source ref: work/canonical-skin-001-016-registry
- Source commit: c8dcd49f829149049da52ddc1ee4b14e6f60e243
- Manifest path: SKIN/Skin_053/theme.json

The REV.18 theme specification identifies logical SKIN-1 with the canonical skin-053/Skin_053 payload. Do not substitute the older SKIN/Skin_01 folder (Neon Riot).

The PNG hero/preview, SVG finish layers and SVG utility icons were copied without redesign. The manifest structure and layout metadata are retained, while its 23 color tokens are intentionally aligned to the user's approved reference mockups: navy/black metallic surfaces, electric blue/cyan primary accents, and purple/magenta secondary accents. These visual-only changes do not alter audio, MIDI, sample data, PPGU parameter IDs or workflow behavior.

The source theme's typography metadata remains Segoe UI / Consolas. The optional Inter font package was not activated or bundled because the PPGU theme itself declares these existing UI fonts as authoritative.
