# SIGNALS — SKIN 001
**Experimental art package for POP PUNK GUITAR ULTIMATE REV.20**

## Included artwork
- 1920×1080 PNG RGBA background and 720×405 preview.
- 4096×4096 brushed graphite and 2048×2048 smoked-glass textures.
- Independent cyan bloom, blue bloom and edge-reflection layers.
- Four-state knob and button sprite atlases with explicit frame geometry.
- Reusable knob PNGs and original abstract electric-guitar stage hero.
- SVG bezel, crest and procedural texture.
- JSON theme and artwork manifest with dimensions, modes and SHA-256 checksums.

## Visual direction
Graphite/anodized metal, dark titanium, smoked glass, restrained cyan/electric-blue lighting. This is an artwork/material pass intended to overlay the approved NEON STAGE DEFAULT geometry.

## Compatibility safeguards
No APVTS IDs, control semantics, DSP, MIDI, sampler, presets, audio callback or functional geometry are changed. No fake backend activity or unsupported functional states are represented.

## Status
Experimental artwork only. The original mockup PNG was not readable through the GitHub binary-content endpoint in this session, so pixel-exact matching is not claimed. Runtime integration, Windows VST3 build, pluginval and FL Studio 20 acceptance remain unverified. The package is on a separate branch and is not registered as an official seventeenth skin.
