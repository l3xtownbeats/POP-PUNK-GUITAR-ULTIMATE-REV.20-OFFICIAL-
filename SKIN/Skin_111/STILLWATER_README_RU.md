# STILLWATER — SKIN-10 / skin-111

## Итог графического этапа

STILLWATER оформлена как отдельная визуальная тема существующей SKIN-10. Количество тем остаётся строго **16**. Стабильный ID `skin-111`, ordinal 10, сетка и действующие control IDs сохранены.

### Обязательный эталон 1:1

Главный исходный макет находится в корне репозитория:
`01 INTERFACE  NEON STAGE DEFAULT .png` (исходный файл, не перерисованная SVG-заготовка).

Это обязательный геометрический и композиционный эталон STILLWATER. Требование — совпадение 1:1 по:
- внешним границам окна, пропорциям и внутренним отступам;
- координатам, размерам и взаимному расположению всех панелей;
- размерам и позициям каждого элемента управления, дисплея, подписи и индикатора;
- исходной структуре и визуальной иерархии интерфейса.

Изменяется только skin-представление: палитра, материал поверхностей, текстуры, блики, тени и декоративная отделка. Запрещены произвольная компоновка, переосмысление дизайна, замена элементов на условные образцы и сдвиг контролов ради декоративной графики.

Приёмка 1:1 выполняется наложением STILLWATER на исходный PNG с проверкой границ/координат и сравнением каждого участка. Текущие SVG specimen-файлы не считаются доказательством совпадения; их нужно привести к эталонной геометрии. До такой проверки тема остаётся runtime-gated.

### Границы готовности
Шесть базовых SVG-слоёв (texture, bezel, crest, controls, fx_layers, decorative) и манифест STILLWATER уже включены в цель `PPGUData` через `juce_add_binary_data`; редактор загружает их из `BinaryData`. Для выбора STILLWATER не требуется внешняя папка `Skins` или копирование её графических файлов рядом с VST3. В автономном режиме редактор сохраняет слот 10 и использует встроенную тему как fallback.

Остальные SVG specimen-файлы (rotary, FX switches, display frames, keyboard, state atlas, PATTERN workspace) остаются справочными ресурсами, а не подключёнными runtime-контролами. ## Неприкосновенные ограничения
- Ровно 16 тем; SKIN-17 не создавать.
- SKIN-1 NEON STAGE DEFAULT / skin-053 остаётся темой по умолчанию.
- STILLWATER — SKIN-10 / skin-111.
- Только два главных режима: MELODY и PATTERN.
- AUTOCHORDS остаётся дополнительным окном внутри PATTERN.
- Не менять DSP, аудиодвижок, MIDI, APVTS, control IDs, layout geometry и семантику пресетов.
