# NEON STAGE PNG migration

This directory is generated by `tools/migrate_neon_stage_png.py`.

- Source artwork remains in `artwork_batch_01` through `artwork_batch_08`.
- Batch PNG derivatives are written beneath `assets/png_migration/<batch>/` at 1x/2x/3x.\n- The canonical `svg/texture.svg`, `svg/bezel.svg`, and `svg/crest.svg` sources are rendered to `assets/png_migration/runtime_artwork/{texture,bezel,crest}.png` at the exact runtime dimensions.
- Every converted image is RGBA PNG at the SVG's declared dimensions/viewBox.
- `png_manifest.json` records source and PNG SHA-256, dimensions, alpha extrema, and palette tokens.
- The converter rejects malformed SVG, missing dimensions, failed renders, incorrect PNG mode/dimensions, and explicitly forbidden purple/magenta accent tokens.
- SVG sources are retained as editable source material during migration.
- The three canonical texture/bezel/crest layers are loaded by JUCE from generated PNG paths. Batch control artwork still needs individual editor component bindings and host/visual verification.
