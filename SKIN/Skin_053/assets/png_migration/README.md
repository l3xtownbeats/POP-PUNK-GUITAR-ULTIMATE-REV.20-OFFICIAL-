# Legacy NEON STAGE artwork migration — unapproved transitional assets

**Status: NOT A PRODUCTION ASSET PIPELINE. These files are not approved final artwork.**

This directory records an earlier migration experiment. Its SVG sources and PNG derivatives rendered from those SVG sources are legacy placeholders only. They do not satisfy the approved PNG-only production-artwork requirements and must not be used as production masters or intermediate render inputs.

**Known migration debt:** the current Skin-1 theme manifest and ThemeManager still load three PNG derivatives from `runtime_artwork/{texture,bezel,crest}.png`. Their presence is a compatibility carry-over, not production approval. They must be replaced by individually authored, reference-reviewed PNG production assets before the visual migration can be called complete. Do not claim that the runtime is already free of these references.

The production pipeline is defined by:

- `../png_asset_contract.json`
- `../artwork_manifest.json` (inventory only; not a declaration that every listed asset is production-approved)
- `../ASSET_OPEN_ISSUES.md`
- `docs/NEON_STAGE_ALL_WINDOWS_ASSET_SCOPE_RU.md`
- `docs/NEON_STAGE_PNG_ONLY_AND_PATTERN_WORKSPACE_LOCK_RU.md`

New production artwork must be authored as independent RGBA PNG assets, with high-resolution masters (at least 4x for major panels/details relative to the 1024x700 reference canvas), 1x/2x/3x runtime variants where applicable, and a manifest containing semantic ID, exact dimensions, alpha, state, scale, master relationship, and SHA-256. No production asset may be generated by rasterizing a legacy SVG.

Do not delete this legacy directory during the migration: it is retained for audit/history only. Do not add new generated files here. The three currently referenced PNG derivatives are temporary compatibility assets and must not be represented as final visual components.

A successful legacy conversion, PNG decode, CI run, or manifest parse does not establish visual parity, production approval, or FL Studio 20 host acceptance.
