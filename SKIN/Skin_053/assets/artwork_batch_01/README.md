# NEON STAGE ARTWORK — Batch 01

Status: **vector foundation created; visual acceptance pending**.

These are three separate, transparent-capable SVG production primitives for Skin 053:
- `panel_frame.svg` — 960×560 auxiliary-panel frame.
- `rotary_knob_01.svg` — 160×160 rotary base, with no baked label or value.
- `fx_switch_01.svg` — 112×72 FX switch housing/indicator.

Palette is restricted to graphite `#080B14`, `#101827`, `#17243A`, cyan `#00D9FF`, and electric blue `#6B8CFF`. No magenta, purple or violet is used.

Important limitations:
- These files are vector primitives, not a claim that the full NEON STAGE reference has been reproduced.
- The original approved hero image is not replaced by a synthetic vector hero.
- Knob and switch files are base artwork only; required normal/hover/pressed/active/disabled/focus states are not yet complete.
- Dedicated panels for FX EDIT, Import Guitar, Settings, AutoChords and Skin Gallery, keyboard key assets, LCD/LED, hardware details, exact reference visual audit and runtime integration remain open.
- No functional controls, APVTS IDs, DSP, MIDI, presets or audio behavior were changed.

All dimensions and checksums are recorded by Git's blob objects; raster exports and alpha-channel validation remain a later packaging gate.
