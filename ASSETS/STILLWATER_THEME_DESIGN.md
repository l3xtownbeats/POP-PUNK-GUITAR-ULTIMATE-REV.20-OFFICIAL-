# STILLWATER — визуальная спецификация темы PPGU REV.20

**Статус:** DESIGN DRAFT / подготовка визуальных ресурсов  
**Предлагаемое место в закрытом наборе:** SKIN-10, текущая тема DEEP OCEAN  
**Существующая идентичность-кандидат:** `skin-111` / index `111`  
**Ограничение:** тема НЕ добавляется как SKIN-17. До отдельного подтверждения замены реестр 16 тем и runtime-имя DEEP OCEAN не меняются.

## 1. Арт-направление

STILLWATER — спокойная премиальная студийная консоль с атмосферой глубокой неподвижной воды. Не киберпанк и не яркий неон. Визуальная основа: тёмный сине-графитовый корпус, холодное матовое серебро, полупрозрачные стеклянные LCD-поверхности и тонкие бирюзовые индикаторы. Поверхности выглядят как анодированный металл с мягкими отражениями, а не как плоские цветные карточки.

## 3. Материалы и графика

- **Background:** плавный градиент от почти чёрного морского синего к графиту; едва заметные горизонтальные интерференционные линии, как рябь на неподвижной воде.
- **Panels:** матовый анодированный металл, тонкая внутренняя фаска, мягкая контактная тень.
- **Controls:** металлические энкодеры с холодной серебристой насечкой; бирюзовый указатель только для текущего значения/фокуса.
- **LCD:** тёмное стекло с тонкой рамкой и чистой читаемой типографикой.
- **LED:** компактные точки без постоянного свечения; свечение только в активных состояниях.
- **Hero artwork:** абстрактная спокойная водная глубина и отражённая линия света; никаких чужих логотипов, фотографий артистов или декоративных надписей, имитирующих реальные статусы.

## 4. Окно PATTERN

Сохраняется утверждённая структура REV.20:
1. Главный селектор режима содержит только **MELODY** и **PATTERN**.
2. PATTERN workspace показывает браузер паттернов/категорий, выбранный паттерн, источник гитары/тон, параметры исполнения и доступные элементы управления.
3. **AUTOCHORDS** открывается как дополнительное окно из PATTERN, не как третий главный режим.
4. FX EDIT, Import Guitar, Pattern Routing, Skin Gallery, Settings и диалоги — вспомогательные окна.
5. Любые названия, значения, ноты, MIDI-подсветка, meters и LED остаются динамическими элементами интерфейса, а не запечёнными в PNG.

## 5. Правила реализации

- Только visual-only skin. Не менять DSP, audio callback, sampler, MIDI, APVTS, preset behavior или layout geometry.
- Сохранить 27 пользовательских control IDs, девять основных rotary bindings и семь утверждённых FX bypass IDs.
- Сохранить существующие состояния NORMAL/HOVER/PRESSED/ON/DISABLED там, где они предусмотрены схемой.
- Не показывать недоступные функции как работающие.
- Типографика: Segoe UI для интерфейса, Consolas для чисел и технических значений.
- Glow выключен в обычном состоянии и включается только для hover/focus/active/status.
- Текущий закрытый набор содержит ровно 16 тем. Эта спецификация не создаёт дополнительный ordinal и не меняет registry.
